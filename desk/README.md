# 부자유통 발주 알림센터 (사무실 Windows 프로그램)

거래처가 주문사이트에서 **주문 확정**을 누르면, 사무실 PC에 알림음과 팝업이 뜨고
직원은 주문을 보고 얼마에요에 직접 입력한 뒤 **[입력완료]** 를 누르는 프로그램입니다.

관리자 웹페이지에는 아무 기능도 추가하지 않았습니다. (상품·가격·거래처 관리만 그대로)

## 설치 (사무실 PC마다 한 번)

1. GitHub → **Actions → "Desk Windows EXE (발주 알림센터)"** 최근 성공 실행 → 아래 **Artifacts** 에서
   `BujaOrderAlert-Setup-x.y.z` 를 내려받아 압축을 풉니다.
   (태그 `desk-v1.0.0` 을 올린 경우 **Releases** 에서 바로 내려받을 수 있습니다)
2. `BujaOrderAlert-Setup-x.y.z.exe` 실행 → 관리자 권한 없이 설치됩니다.
   - 서명되지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
   - "Windows 시작 시 자동 실행"은 기본으로 켜져 있습니다.
3. 처음 실행하면 **직원 아이디 + 6자리 PIN**(배송기사 앱/관리자 화면과 같은 직원 계정)으로 로그인합니다.
   PC 이름(예: 사무실1)은 처리자 기록에 함께 남습니다.

로그인 정보는 이 PC의 Windows 사용자 계정으로만 풀 수 있게 암호화(DPAPI)되어
`%LOCALAPPDATA%\BujaOrderAlert` 에 저장됩니다. 프로그램(EXE)에는 비밀번호나 인증키가 들어 있지 않습니다.

## 사용

| 화면 | 내용 |
|---|---|
| 처리할 발주 | 입력완료 전 주문 전체. 신규가 위, 오래된 순. 배송일·상태 필터, 검색, 거래처별 묶어 보기 |
| 주문 상세 | 거래처, 배송일, 오전/오후 발주, 접수시간, 배송처, 요청사항, 품목표(상품명·규격·단위·수량) |
| 버튼 | **입력 시작**(다른 PC에 '입력 중' 표시) → 얼마에요 입력 → **입력완료** (되돌리기 가능) |
| 처리내역 | 접수일/배송일 기간, 거래처·상품명 검색, 처리자·처리시간 |

- 🚨 **추가발주**: 같은 거래처가 같은 배송일로 이미 주문한 뒤 또 주문한 경우
- **입력 중**: 다른 직원이 입력 중이면 이름이 보이고, 동시에 [입력 시작]을 누르면 한 명만 성공합니다.
- **취소 확인 필요**: 거래처가 접수 후 취소한 주문. 얼마에요에 입력했다면 정리한 뒤 [취소 확인].
- 창을 닫아도 트레이(오른쪽 아래)에서 계속 실행됩니다. 완전 종료는 [설정 ▾ → 프로그램 종료].
- 미처리 '신규' 발주가 10분 넘게 남아 있으면 다시 알려 줍니다(설정에서 끌 수 있음).

## 누락 방지 동작

- 주문은 서버(Cloudflare D1)에 저장됩니다. PC가 꺼져 있어도 다시 켜면 미처리 주문이 모두 보입니다.
- 10초마다 변경 여부를 확인하고(바뀐 경우에만 목록을 받음, 서버 읽기량 최소화), 인터넷이 끊기면 자동 재시도 후 다시 전체를 받습니다.
- 이미 알린 주문은 PC에 기록해 두어, 프로그램을 다시 켜도 같은 주문으로 다시 알리지 않습니다.
- 입력완료를 누르기 전에는 목록에서 사라지지 않습니다.

## 개발

```
cd desk
python -m pip install -r requirements-build.txt
python -m pytest tests/test_core.py          # 핵심 로직 (Qt 없이)
python -m buja_desk                           # 실행
BUJA_DESK_SERVER=http://localhost:4173 python -m buja_desk   # 로컬 서버로 실행
python -m PyInstaller packaging/BujaOrderAlert.spec          # EXE (Windows)
```

서버 API: `src/lib/desk.server.ts`, `src/routes/api/desk/*` (Authorization: Bearer 토큰 전용)
